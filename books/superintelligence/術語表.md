# 翻譯術語表

適用於本專案的繁體中文翻譯初稿；隨後續章節的語境校訂。

| 英文 | 暫定繁體中文 | 備註 |
|---|---|---|
| superintelligence | 超級智慧 | 全書核心概念 |
| general intelligence | 通用智慧 | 與特定領域的能力區分 |
| artificial intelligence | 人工智慧 | 縮寫 AI |
| machine intelligence | 機器智慧 | 不一律替換成「人工智慧」 |
| control problem | 控制問題 | 不直接改寫為「對齊問題」 |

| existential catastrophe | 存續性災難 | 涉及人類存續或長期潛能的根本損失，不限於立即滅絕 |
| human values | 人類價值 | 指價值取向，不是經濟價值 |
| null hypothesis | 虛無假設 | 前言採類比用法 |
| artificial general intelligence (AGI) | 通用人工智慧 | 與範圍狹窄的專用系統區分 |

| ultraintelligent machine | 超高智慧機器 | 保留 I. J. Good 引文的用詞差異 |
| existential risk | 存續性風險 | 與存續性災難相對應 |

| neural network | 神經網路 | artificial neural network 譯為人工神經網路 |
| genetic algorithm | 遺傳演算法 | 不與遺傳程式設計混用 |
| genetic programming | 遺傳程式設計 | 以程式作為演化候選解 |
| fitness function | 適應度函數 | 演化搜尋中的篩選準則 |
| combinatorial explosion | 組合爆炸 | 搜尋或推論中的可能組合急劇增加 |
| heuristic search | 啟發式搜尋 | heuristic 視語境譯為啟發式規則或方法 |

| backpropagation | 反向傳播 | 神經網路訓練方法 |
| graceful degradation | 平緩退化 | 局部損傷不造成全盤失效 |
| connectionism | 連結主義 | 強調平行次符號處理 |
| maximum likelihood estimation | 最大概似估計 | 統計術語 |
| inductive bias | 歸納偏置 | 學習方法預設的偏好或假設 |
| Bayesian agent | 貝氏行動者 | 與 agent 的既定譯法一致 |
| Bayesian network | 貝氏網路 | 機率圖模型之一 |
| prior / posterior probability distribution | 先驗／後驗機率分布 | 不與頻率混用 |
| Kolmogorov complexity | 柯爾莫哥洛夫複雜度 | 依最短程式描述長度衡量 |
| utility function / expected utility | 效用函數／預期效用 | 決策理論術語 |
| probabilistic graphical model | 機率圖模型 | 第一章相關技術分類 |
| Monte Carlo approximation | 蒙地卡羅近似 | tree search 譯為樹搜尋 |
| AI-complete | AI 完全 | 原書指與實現通用人類水準 AI 相當的難度 |
| hidden Markov model | 隱藏式馬可夫模型 | 第一章語音辨識例子 |
| temporal difference learning | 時間差分學習 | 一種強化學習方法 |
| high-frequency trading | 高頻交易 | 保留演算法交易的具體市場語境 |
| whole brain emulation (WBE) | 全腦模擬 | 指重建生物腦的運算功能；不等同於所有一般性的腦模擬 |
| uploading | 上傳 | 第二章作為全腦模擬的別稱 |
| qualia | 感質 | 指主觀經驗的質性特徵 |
| child machine | 兒童機器 | Turing 提出的學習系統構想 |
| seed AI | 種子 AI | 能進一步改進自身架構的 AI |
| recursive self-improvement | 遞迴式自我改進 | 保留迭代增強與可能智慧爆炸之間的條件關係 |
| neuromorphic AI | 神經形態 AI | 受大腦運作原理啟發，不必是完整腦模擬 |
| observation selection effect | 觀察選擇效應 | 不因觀察者存在而直接推論智慧演化原本很可能發生 |
| vitrification | 玻璃化 | 全腦模擬一節的組織保存處理 |
| nootropics | 促智藥物 | 保留作者對效果及副作用的不確定判斷 |
| in vitro fertilization (IVF) | 體外受精 | 保留原表 IVF、IVF+ 等技術標籤 |
| iterated embryo selection | 反覆胚胎篩選 | 指跨多個實驗世代反覆篩選的構想 |
| heritability | 遺傳率 | 為特定人群與環境下的變異比例，非個體能力的遺傳百分比 |
| additive genetic variant | 加性遺傳變異 | 第二章胚胎篩選模型中的術語 |
| mutational load | 突變負荷 | 不直接等同於每個新突變都有害 |
| germline intervention | 生殖系介入 | 對配子或胚胎的介入 |
| somatic gene enhancement | 體細胞基因增強 | 與生殖系介入區分 |
| brain–computer interface | 腦機介面 | 可涵蓋讀取與輸入；不預設一定提升智慧 |
| collective superintelligence | 集體超級智慧 | 多個心智組成系統的整體能力 |
| quality intelligence | 品質智慧 | 指智慧在質的層面上的差異；第三章完整分類使用「品質超級智慧」 |

| speed superintelligence | 速度超級智慧 | 能做人類智慧體所能做的一切，但快得多 |
| quality superintelligence | 品質超級智慧 | 至少與人類心智同速，且在質的層面上聰明得多 |
| intelligence quality | 智慧品質 | 與單純加速或增加集體規模區分 |
| wisdom | 明智 | 第三章指在重要事情上大致作出正確判斷；與 intelligence 區分 |
| direct reach / indirect reach | 直接能力範圍／間接能力範圍 | 後者包括透過發展技術、創造其他智慧形式而達到的能力 |
| working memory | 工作記憶 | 記憶容量以資訊組塊描述時不直接等同電腦 RAM |
| chunk | 資訊組塊 | 工作記憶中的功能單位 |
| copy clan | 複本族群 | 共享同一目標、相同或近乎相同的程式群體 |
| global workspace theory | 全域工作空間理論 | 第三章原作者註 12 的意識理論 |
| Church–Turing thesis | 邱奇–圖靈論題 | 形式上的可計算性不等同實務求解效率 |

| takeoff | 起飛 | 從人類水準智慧到強超級智慧的轉變階段 |
| human baseline / civilization baseline | 人類基準／文明基準 | 分別錨定原著時點的代表性個人能力與全人類總能力 |
| strong superintelligence | 強超級智慧 | 遠超當代全人類智力總和的程度 |
| optimization power | 最佳化力量 | 依品質加權、用於改進系統的設計投入；公式記作 O |
| recalcitrance | 抗改進性 | 系統對最佳化投入之反應程度的倒數；不是意志上的頑固 |
| crossover | 交越點 | 系統自身成為其改進之主要最佳化力量來源的時點 |
| hardware / content / algorithm overhang | 硬體／內容／演算法儲備餘裕 | 系統達到關鍵能力後即可利用的既有資源或改進，不指過時庫存 |
| maturational lag | 成熟所需的等待期 | 生殖系介入須等待個體成長的時間限制 |
| monopsony power | 買方壟斷力量 | 與賣方壟斷區分 |

## 翻譯原則

- 採自然、忠於原意的繁體中文，保留作者的條件、推測強度與不確定性。
- 重要術語首次出現時附英文；不把後來的 AI 術語或觀點代入原文。
- 保留原作者註釋，清楚區分譯稿說明與正文。
- EPUB 作為文字提取輔助；段落、公式、圖表與註釋以 PDF 核對。
